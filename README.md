# C++ Object-Oriented Programming: Classes & Objects

A C++ application demonstrating object-oriented fundamentals, including class creation, private/public encapsulation, constructors, member functions, and standard vector management.

## C++ Concepts Covered
* **Classes & Objects**: Blueprint design (`class`) and instantiation of object instances.
* **Encapsulation**: Restricting direct data access using `private` and exposing controlled interfaces via `public` member functions.
* **Constructors**: Automatic initialization routines executed upon object creation.
* **Standard Library Vectors (`std::vector`)**: Managing dynamic collections of objects in C++.

## How to Compile & Run
```bash
g++ main.cpp -o oop_classes
./oop_classes
